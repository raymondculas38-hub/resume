# Raymond Culas - Portfolio Website

A clean, modern, and interactive developer portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Interactive Cinematic Hero:** A custom light/dark theme interaction that morphs a static portrait into a video.
- **Projects Timeline:** An interactive showcase of academic and freelance projects.
- **Tech Stack Showcase:** Grid display of mastered languages, frameworks, and databases with high-quality icons.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion, React Icons
- **Build Tool:** Vite
- **Deployment:** Vercel

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
